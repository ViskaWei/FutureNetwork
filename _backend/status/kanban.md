# 📎 快捷命令

| 命令 | 作用 |
|------|------|
| `?` / `status` | 查看整体进度 |
| `a` / `归档` | 进入归档流程 |
| `n [描述]` | 新建实验计划（立项） |
| `sync` | 同步实验索引 |
| `p [id]` | 生成 coding prompt |

---

> **使用说明**：
>
> **核心原则**：
> - 一个 experiment_id 只在一个状态列中出现
> - 状态转换时带上时间戳和关键信息
> - 保持简洁，详细信息在 exp.md 中
>
> **与其他文件的关系**：
> - `sessions/` → Inbox 的来源
> - `kanban.md` → 实验执行的中控台
> - `exp.md` → Done → Archived 的产出
> - `hub.md` → 汇总 Archived 的结论
